# EduMetrics – Student Performance Analytics System

EduMetrics is a Python-based data analysis project that analyzes student academic performance using **Python, NumPy, and Pandas**. It calculates total and average marks, assigns grades, identifies pass/fail students, analyzes subject-wise performance, and identifies top performers.

### Technologies Used
- Python
- NumPy
- Pandas

### Key Features
- Student marks and average analysis
- Grade and pass/fail calculation
- Subject-wise performance analysis
- Identification of top performers
- Overall class performance statistics
